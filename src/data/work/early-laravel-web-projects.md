# Early Laravel and Web Projects

## Context

Before the current portfolio rebuild, an older PDF portfolio documented
several 2022–2023 learning and early delivery projects. These projects
are useful as background because they show the start of the Laravel, PHP,
Bootstrap, HTML, JavaScript, and CSS work that later continued into
professional roles.

This page keeps them grouped as one early-project entry instead of
creating many small case studies with limited evidence.

## Projects listed in the archived portfolio

### Storage Information System for School

A Laravel, PHP, HTML, JavaScript, CSS, and Bootstrap web application for
recording stored items, transactions, loan activity, and return data for a
school context.

### Codero

A company website built with Laravel, PHP, HTML, JavaScript, CSS, and
Bootstrap.

### Guruinovatif.id

The archived portfolio also lists Guruinovatif.id as a Laravel and
Tailwind project with online course, article, event, affiliate, and
membership features. The current portfolio now treats Guruinovatif.id
under the more accurate Hasnur Centre workplace boundary.

### Other archived practice builds

The scanned portfolio also shows earlier mobile and website project names
such as Mid Gun, Mid Wali, Si Masjid, Kurma Batam, Bahtera Amal, and SPS.
Those are not expanded into standalone case studies yet because the
available source does not include enough detail for each one.

## Technology

Laravel · PHP · HTML · JavaScript · CSS · Bootstrap · Tailwind.
