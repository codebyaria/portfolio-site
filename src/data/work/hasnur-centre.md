# Hasnur Centre

## Context

[Hasnur Centre](https://guruinovatif.id/) is an Indonesian education
holding that develops teacher-training and workforce-development
products. One of the products shipped during this role was
[Guruinovatif](https://guruinovatif.id/) — an online teacher-development
platform offering courses, webinars, and certification programmes
(BerJP) for Indonesian teachers. This case study covers the
contributions I owned as part of the engineering team at Hasnur Centre
between August 2022 and January 2024, including the Guruinovatif
product surface.

## Dates and work arrangement

August 2022 – January 2024, Fullstack Web Developer (1 year 6 months)
based in Yogyakarta, Indonesia.

## Role

Web Developer on the engineering team. Contributions below were owned
end-to-end: from the data model, through the application logic, to the
front-end integration on the public marketing surface. The team
collaborated through every phase of the systems development life cycle
using GitHub for source control and Notion for team documentation.

## Contributions

### 1. Source-tracking layer

**Problem.** The marketing team needed to attribute registrations and
other key actions to specific traffic sources so that acquisition
channels could be compared honestly.

**Action.** Implemented a source-tracking layer on the registration
flow so that each new user account could be tied back to its
acquisition channel.

**Result.** Delivered as part of the overall platform work.

### 2. Events feature

**Problem.** The platform needed a way to surface upcoming and past
training events to teachers, integrated with the existing Laravel
application rather than as a separate tool.

**Action.** Built the events feature: listing and detail views,
integrated with the existing application surface and the same content
workflow used by the rest of the platform.

**Result.** Delivered as part of the overall project work.

### 3. Affiliate system

**Problem.** There was no programme for teachers to refer other
teachers and be credited for the referral.

**Action.** Implemented an affiliate layer so that existing users could
refer new users and the system could track that relationship end-to-end.

**Result.** Delivered as part of the overall project work.

### 4. Public landing page

**Problem.** The platform needed a public landing page that
communicated its offering and converted visitors into registered
accounts.

**Action.** Built and maintained the public landing page using Laravel
with Tailwind and Bootstrap used in distinct parts of the page (Tailwind
for the newer sections, Bootstrap where it was already present in the
existing component library).

**Result.** Delivered as part of the overall project work.

## Outcome

Shipped and maintained the events + affiliate + source-tracking layer,
plus the public landing page, for the Guruinovatif platform during my
tenure at Hasnur Centre. Delivered as part of the overall platform work.

## Technology

Laravel · Tailwind · Bootstrap · MySQL · GitHub · Notion.
