# Analytics Integrations

## Context

Analytics integration work delivered across multiple projects — both
self-initiated portfolio pieces and client engagements. The platforms
in scope are GA4, Google Search Console, Google Tag Manager, Meta
Pixel, TikTok Pixel, Google Ads conversion tracking, Microsoft Clarity,
and Hotjar. Project identities are deliberately not disclosed in this
entry; it covers the recurring shape of the work.

## Dates and work arrangement

Ongoing. Each project receives analytics setup at launch, then
incremental event-tracking updates as features are added.

## Role

Web Developer with analytics focus. Responsibilities include initial
property setup, event schema wiring through Google Tag Manager,
conversion API configuration, and ad-platform pixel validation.

## Contributions

### 1. Initial property and tag wiring

**Problem**: Projects launch without a unified analytics layer,
making it impossible to attribute traffic and conversions to
specific sources.

**Action**: Set up GA4, Google Search Console, and Google Tag
Manager; wired the base pageview and outbound-click events
through Tag Manager; verified events in GA4 DebugView.

**Result**: Pending evidence — no isolated metric attributable to
this contribution.

### 2. Ad-platform pixel and conversion API

**Problem**: Paid traffic from Meta and TikTok needs server-side
conversion attribution, not just browser-side pixel events.

**Action**: Implemented Meta Pixel + Conversions API, TikTok Pixel

- Events API, and Google Ads conversion tracking. Validated
  deduplicated events server-side.

**Result**: Pending evidence.

### 3. Behaviour analytics setup

**Problem**: Quantitative analytics alone does not show _why_
users behave a certain way on a page.

**Action**: Set up Microsoft Clarity and Hotjar on production
projects to capture session replays and heatmaps, with consent
mode for EU traffic where required.

**Result**: Pending evidence.

## Outcome

Set up and maintained analytics integrations across multiple
projects spanning GA4, Search Console, Tag Manager, Meta Pixel
and Conversions API, TikTok Pixel and Events API, Google Ads,
Clarity, and Hotjar. Specific conversion lift, attribution
accuracy, or session-replay findings not isolated to this
contribution; left as pending evidence rather than rounded up.
